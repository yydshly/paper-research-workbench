FIRST THE QUESTION. THEN THE EVIDENCE.

先把论文从哪里来、
怎么找、怎么用讲清楚。

一个面向具体科研阅读任务的独立产品：找到值得细读的论文，读懂方法与图表，再带着证据讨论研究方向。决策由人完成。

初期候选：生命科学 / 生物研究生公开示例：DESeq2单一 main 主线
当前优先级：研究与需求展示 → 确认数据源与样例 → 分阶段实现。

已做的真实检索原型被保留；暂停超前功能扩展。网页展示、真实数据链路与模型解读分别验收，不合并为“产品已完成”。

SEARCH DESIGN

怎么搜，为什么排在前面

03 / 08
1

明确问题

整理对象/体系、核心问题、方法、指标和纳排条件。用户可改关键词、同义词、年份和预印本范围；未发表设想只提取必要公开关键词。

2

广召回与留痕

词项与领域词表组合，先取约 50–100 条候选，不足如实显示。保存实际查询式、数据库、过滤器与 UTC 时间。

3

去重与可解释排序

DOI / PMID / PMCID 映射与版本辨认，展示前 20 篇。每项匹配必须有标题/摘要/全文依据，未知不偷换成不相关。

已验证的工程原型

当前仅是词项基线

标题覆盖 60% + 摘要覆盖 40%，在取回的候选内排序，能展开命中词与分项权重。没有语义模型，没有五维推理，没有正确率或创新性承诺。

引用量、期刊名都不用于本原型排序；科学质量与偏倚风险应另行评估。

READING & EVIDENCE

读懂之后，仍然要能核对

04 / 08

1–3 篇按需精读

  • 原文与译文对照；术语保留英文，逐项检查否定、单位、公式和比较组。
  • 图表依次核查 panel、坐标、图例、样本量、误差线与统计检验。
  • 缺正文只给摘要层级判断，不能编造 Methods 或图表细节。
  • 解释绑定原文证据；模型推断、教学类比与合成例子单独标识。

VALIDATION & COST

先设验收，再讨论收费

07 / 08
以下是待试验目标，不是表现承诺

领域与科学质量

10 个公开问题，2 名领域读者独立标注。建议已知关键论文 Recall@20 ≥80%、前 10 可用相关度 ≥80%；需报告候选池限制和评审一致性。

抽查至少 30 条解释和 10 处术语/数值，目标证据支持 ≥95%；虚构引用和关键数值错误为 0。当前模型未接入，尚无这些实测结果。

已完成的是工程测试

功能路径与失败恢复

24 项模拟/本地 HTTP 测试通过；真实网络查询 75 条，前 20 篇可解释词项分；DESeq2 37 分节、141 段、9 条原文图注。

真实空结果、缺全文与缓存已验证；模拟覆盖错误、未知/受限许可、429 与超时。浏览器桌面及 390px 窄屏通过，真实模型调用 0。

单任务成本 = 检索 + 模型输入/输出 + 图像/OCR + 存储带宽 + 重试 + 人工抽查

Europe PMC API 调用费为 0，不代表产品总成本为 0。OpenAlex 是按操作计费且有每日免费预算，尚未接入；模型、图像分辨率、文章长度和调用轮数未定，因此没有可信的单篇成本或订阅利润率。先批准预算上限，再测冷/热缓存的 P50/P95 耗时、费用与失败率。

范围与隐私

不承诺完整系统综述、文字查重、全学科覆盖、自动写论文或自动实验。无付费、租 GPU、新凭据/账号或扩大授权。检索词会发到数据源；默认只用公开必要关键词，不将完整未发表设想发送给第三方，不提交私人信息或密钥。
