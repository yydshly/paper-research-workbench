# 产品需求

## 核心任务

面向需要理解某个具体课题的研究者。主线是查询能力与读懂能力；查新与后续采用核查是后续的证据能力，最终研究决策由人完成。

1. 用户输入可明确检索的课题或 Europe PMC 查询式。首期面向生命科学，支持英文关键词/布尔式；中文课题暂不自动翻译或声称跨语种召回。
2. 从 Europe PMC 实时取得 50–100 条候选（不足则如实显示），按 DOI、PMCID、来源标识符去重。展示真实命中数、采集时间、查询式和前 20 篇可解释相关度。
3. 用户选 1–3 篇允许处理的开放论文。核实 API 元数据与全文权限；展示原文段落、章节、图注、原文锚点、许可证、采集时间与内容哈希。
4. 后续在授权真实模型上做按需双语阅读、术语/方法解释、一张图解释。每项输出必须可回到原文，保留不确定性与模型信息。当前模型未接入。
5. 后续核查相近研究与后续采用：相似主题、引用、方法提及、实际采用分别记录，不能互相替代。

## 本轮纵向范围

提供可运行网页和真实数据链路，不只交静态计划。首期不提供账号、多用户、收费、私有文件上传、自动决策、大规模抓取、向量库或模型假输出。全文阅读是 JATS 结构化正文，非 PDF 版式复刻；复杂公式/表格需通过原文链接核对。

## 约束

独立于 azure-reef-3d、coffee 等项目；仓库采用 `main`，阶段提交。保持私有，公共发布需另行确认。无付费、租 GPU、新账号、新 API 凭据或权限扩张。已有工具的认证仅用于授权的建库与提交。
