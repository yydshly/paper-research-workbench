# 验收

| 路径 | 预期 |
| --- | --- |
| 真实课题 | Europe PMC 返回约 50–100 条候选；前 20 条有分项解释与来源 |
| 空结果 | 返回 0 与调整建议，不能回退到示例结果冒充 |
| 无效输入 | 空白、超长、非法数量返回 400 |
| 上游错误/断网 | 有限重试、明确错误、允许手动重试，不用预制成功结果 |
| 重复请求/点击 | 前端按钮禁用；服务同 key 合并并缓存，不重复消耗上游请求 |
| 重复文献 | DOI 大小写/URL 规范化；PMCID、来源 ID；支持跨键传递合并 |
| 许可未知、NC、ND | 不下载全文进入处理，不翻译、不重绘；提供来源链接 |
| 全文不可用 | 404 与查看原文建议，阅读篮和已有结果仍可用 |
| 合法开放全文 | XML 权限再次核查，正文/图注可读，URL/许可/UTC/哈希齐全 |
| 来源 ID 不一致 | 拒绝展示不匹配文章 |
| 模型请求 | 返回 `MODEL_NOT_CONNECTED`，界面不显示伪解释 |
| 安全呈现 | 上游文本以 textContent 渲染，不执行 HTML/脚本；静态目录不暴露源码 |
| 移动与键盘 | 可用标签、焦点、状态提示和窄屏排版 |

验证层次分开记录：模拟单元测试验证分支，HTTP 集成验证本地路由与响应，真实网络验收验证 Europe PMC 数据，浏览器检查验证页面交互；它们都不能被称作真实模型测试。未来模型输出还需独立科学质量评估。
