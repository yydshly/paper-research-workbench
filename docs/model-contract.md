# 真实模型接入契约

当前提供方为 `None`，状态 `not_connected`。`POST /api/explain` 始终返回 503 / `MODEL_NOT_CONNECTED`。不探查机器上的其他项目密钥，不新建凭据，不调用未经本项目授权的付费模型。产品不把人工写好的讲解冒充 AI。

未来接口输入：文章 ID、许可证据、原始响应哈希、被选段落 ID 与原文、模式（双语/术语/方法/一张图）、用户问题和语言。后端必须限制在已通过许可门禁的内容内。

未来输出：实际 provider/model、UTC、请求标识、逐项原文引用、段落/图 ID、来源哈希、解释、翻译变更标识与不确定性。缺少支持的推断应标明或拒绝，不能虚构论文结论。图解必须区分原图描述、统计解读和重新绘制，检查图中第三方材料权利。真实输出与模拟测试夹具分开。

接入前必须有明确授权的现有认证与成本边界，先以 DESeq2 CC BY 4.0 单篇验收，并由领域读者检查术语、方法、图注与推断。研究决策不交给模型。
