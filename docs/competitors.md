# 竞品观察

核查日期：2026-10-15。以下只记官方网站提供的定位，不等于独立产品测试；没有付费、登录试用或进行性能对比。

| 产品 | 官方定位/页面可见信息 | 本项目需进一步实测的内容 |
| --- | --- | --- |
| [Elicit](https://elicit.com/) | 文献检索、筛选、信息提取与带引用研究输出 | 检索理由、段落回溯、图表与双语阅读体验 |
| [Consensus](https://consensus.app/) | 官网标题为 AI for Research；页面正文未稳定提取 | 功能、覆盖、原文定位与边界均需实测 |
| [ResearchRabbit](https://www.researchrabbit.ai/) | 文献发现与综述工具 | 相近研究和引用网络的可解释性 |
| [AMiner](https://www.aminer.cn/) | 官网标题包含学术搜索、论文检索、文献追踪等 | 中文阅读、图表理解、来源追溯，未完成实测 |
| [讯飞星火](https://xinghuo.xfyun.cn/) | 官网标题为 AI 助手；不是空白市场的证据 | 论文阅读、中文解释、图表能力需具体版本实测 |

中文解释、论文摘要、图表辅助均不能被本项目当作无人具备的功能。当前差异只是待验证假设：把筛选理由、许可门禁与原文证据放在同一条路径里。不得将未实测项写成竞品缺失、劣势或正确率对比。后续使用同一公开课题、同一时间窗口与相同人工评分标准评测，并记录产品版本和套餐。
