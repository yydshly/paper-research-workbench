# 目标与指标

## 产品假设

特色假设是将可检查的检索理由、许可清晰的阅读、逐段来源定位串成一个紧凑工作流。不是宣称中文或图表解释在市场上无人提供。

| 目标 | 首期可检查指标 | 尚不能声称 |
| --- | --- | --- |
| 找到候选 | 一次真实查询取回 50–100 条，展示不足与去重数 | 全领域、全量召回 |
| 解释排序 | 前 20 篇展示标题/摘要命中词与分项权重 | 相关度等于正确率 |
| 读到原文 | 至少一篇明确开放许可全文，章节/段落/图注可定位 | PDF 全版式或机器理解已完成 |
| 可审计 | URL、UTC 时间、SHA-256、许可、原始 ID | 单次快照能证明所有未来结果 |
| 人可决策 | 明示证据缺口、模型状态与覆盖范围 | 自动保证创新性或方法有效 |

初期相关度公式为标题覆盖率 60% + 摘要覆盖率 40%，各项都按用户关键词占比计算，四舍五入到 0–100。布尔运算符与字段标签不计入关键词，不使用引用数加权。该公式是启发式、未经过人工标注校准，不代表概率、正确率或论文质量。

后续质量评估需由领域研究者标注固定课题集，比较 Recall@100、nDCG@20、解释来源支持率、段落定位准确性和任务完成时间。先建立评测集再作性能宣传。
