# 开发路线

只维护 `main` 一条可展示主线，通过清晰提交记录阶段，不建立多个候选产品版本。

| 阶段 | 交付 | 验收门槛 |
| --- | --- | --- |
| 0 · 立项 | 独立私有仓库、统一 README、需求文档 | 核实无同类重复仓库，说明隐私与成本约束 |
| 1 · 真实数据纵向切片 | 检索、去重、相关度、来源卡、开放阅读、状态页 | 真实 API 和异常路径测试；本轮范围 |
| 2 · 读懂 | 授权模型、按需双语、术语/方法、一张图解释 | 明示实际模型、费用授权、逐项原文证据与人工评测 |
| 3 · 证据核查 | 相近研究、后续采用证据、时间线 | 引用/提及/采用分级，人工复核，覆盖范围和反例 |
| 4 · 产品化 | 研究集合、可导出审计包与适当私有托管 | 独立隐私、成本、部署与恢复验收 |

下一阶段先做原文锚点和复杂表格/公式保真，再用已授权模型完成单篇证据约束解释；没有授权就继续完善检索评测与来源定位，不用预制回答填充。
