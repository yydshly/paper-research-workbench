# 论文研究工作台 · Paper Research Workbench

独立科研论文产品：先把文献找得有理由、读得能回到原文，再积累相近研究与方法采用的证据。研究决策由人完成。

## 当前优先：研究与需求网页

按最新顺序，先审阅 [研究展示页](docs/index.html)，讲清定源、获取方式、检索策略、免费/收费及许可边界，再确认数据源和分阶段实现。Europe PMC 是推荐候选，现有代码仅作可行性原型，不代表用户已最终选定数据源。已做代码保留，暂停功能扩展。

展示页包含 6 项来源对照、需求、竞品、路线、验收目标与实际进度。它是静态研究档案，不执行论文检索，不把模型功能写成已完成。可直接打开 `docs/index.html`，或运行 `scripts/preview_research.ps1` 后访问 <http://127.0.0.1:8766>。

用户已选择公开现有仓库，并保留提交历史。仓库当前为 **public**，GitHub Pages 使用 `main:/docs` 发布研究档案；[部署说明](deploy/README.md) 保留此前私有库的套餐阻塞及后续发布核验方式。不另建仓库、不付费、不重写历史。

## 立即运行

需要 Python 3.10+，无第三方依赖、无 API key、无模型费用。

```powershell
python -m apps.workbench.server --port 8765
```

打开 <http://127.0.0.1:8765>。服务只监听本机。检索与全文读取需要访问 `www.ebi.ac.uk`，如果企业网络拦截，需要由用户在运行环境允许该官方域名。

## 当前交付

阶段 1 已实现：Europe PMC 真实检索 50–100 篇、标识符去重、前 20 篇可解释词项排序、来源卡、1–3 篇阅读篮、许可门禁后的结构化开放全文阅读。网页另有项目文档与运行状态入口。没有接入真实模型，双语翻译、术语方法讲解和图解均标记未接入；不会提供伪装模型调用的预制回答。

公开教学案例是 DESeq2，DOI `10.1186/s13059-014-0550-8` / PMCID `PMC4302049`。这不是任何用户的私人或未发表课题。

## 验证

```powershell
python -m unittest discover -s tests -v
python scripts/validate_live.py
```

单元测试使用模拟传输；`validate_live.py` 会访问真实 Europe PMC 并记录时间、计数和 SHA-256。真实模型测试数量始终为 0，直到明确接入并验收。

可选浏览器验收：本机已安装 Playwright 与 Edge 时，先启动服务，再运行 `python scripts/validate_browser.py`。脚本不安装浏览器或依赖。它将真实网络操作和模拟错误响应分开记录，并生成桌面/移动端截图。

本轮真实验收：75 条候选、前 20 篇解释式评分；DESeq2 CC BY 4.0 全文读取 37 个分节、141 段正文与 9 条原文图注。动态结果可变化，详见 [真实网络证据](evidence/live-validation.json)。

## 网页入口与托管状态

原型本地入口为 <http://127.0.0.1:8765>（需运行上方命令）。没有云端 API 部署。研究展示与原型后端分别发布、分别验收；GitHub Pages 只能展示静态研究网页，不能托管此 Python 服务。未为 Pages 修改仓库可见性或套餐，未创建新凭据。

## 研究与发布边界

相关度是可解释词项匹配分，不是正确率、质量分或创新性判断。引用关系不等于实际采用；不能据此保证原创。PubMed 元数据不代表开放全文。NC、ND 和未知许可全文不进入加工流程。不会默认接入按量付费的 OpenAlex 或需额外商业授权的 Semantic Scholar。

仓库按用户明确选择公开；没有升级套餐、新建仓库或凭据。不读取、提交私人课题、未发表研究、密钥或其他项目内容。代码的对外开源许可尚未决定；可见性公开不等于已授予开源许可，论文权利单独遵循原文许可。
